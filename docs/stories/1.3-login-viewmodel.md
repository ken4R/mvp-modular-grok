# Story 1.3 — ViewModel de connexion

Status: Done

## Story

En tant qu'app iOS ou Android,
je veux un `StateFlow<LoginUiState>` unique,
afin de ne pas réécrire la logique d'écran.

## Acceptance Criteria

1. `onEmailChanged` / `onPasswordChanged` mettent à jour l'état et effacent l'erreur.
2. `submit` passe par `LoginUseCase` et publie la session ou `error.message`.
3. Un second `submit` pendant le chargement est ignoré.
4. Le test fixe `Dispatchers.Main` avec `UnconfinedTestDispatcher`.
5. Le ViewModel et `LoginUiState` sont publics. Le repository reste internal.
6. `authModule` enregistre le ViewModel avec `viewModelOf`.
