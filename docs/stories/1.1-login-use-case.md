# Story 1.1 — Cas d'utilisation de connexion

Status: Done

## Story

En tant qu'utilisatrice,
je veux que des identifiants invalides soient refusés avant tout appel réseau,
afin de ne pas dépendre du repository pour les règles de forme.

## Acceptance Criteria

1. Un email vide, sans `@` ou sans `.` renvoie `Outcome.Failure(DomainError.Validation)` et n'appelle pas le repository.
2. Un mot de passe de moins de 8 caractères renvoie une validation, sans appel repository.
3. Un email valide est trimé puis délégué au repository.
4. `Unauthorized` du repository est propagé tel quel.
5. Les tests vivent dans `:feature:auth:api` `commonTest`.
